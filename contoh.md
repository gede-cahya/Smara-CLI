# Contoh Dokumentasi Smara Discord

## Preview Gambar

> Catatan: Discord biasanya **tidak menampilkan preview SVG langsung** karena alasan keamanan/kompatibilitas. Gunakan PNG/JPG/WebP agar gambar tampil sebagai preview.

![Preview Smara Discord](./smara-discord-preview.png)

## Fitur yang Diinginkan

- Welcome message
- Auto role
- Moderation
- Ticket system
- AI assistant command

## Fitur yang Belum Diinginkan

- Music bot
- Leaderboard
- Invite tracking
- Economy system
- Mini games

## Catatan Implementasi

Jika desain awal masih berupa SVG, sebaiknya dikonversi ke PNG agar bisa tampil langsung di Discord dan mudah dimasukkan ke file Markdown.

Contoh format gambar di Markdown:

```md
![Nama Gambar](./nama-gambar.png)
```

Atau jika gambar sudah di-host online:

```md
![Nama Gambar](https://example.com/gambar.png)
```
