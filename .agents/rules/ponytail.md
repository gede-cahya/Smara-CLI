## ponytail

This project uses [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) — the lazy senior dev skill for AI agents.

Rules:
- Ponytail is ACTIVE by default for all coding tasks (level: full)
- Before writing code, walk the ladder: YAGNI → stdlib → native → dependency → one-line → minimum
- Mark deliberate simplifications with `ponytail:` comments
- Never simplify away: input validation, error handling, security, accessibility
- Use `/ponytail lite|full|ultra|off` to adjust intensity

Skills available:
- `/ponytail` — activate lazy mode
- `/ponytail-review` — review diff for over-engineering
- `/ponytail-audit` — audit whole repo for bloat
- `/ponytail-debt` — list deferred ponytail shortcuts
- `/ponytail-gain` — show benchmark impact scoreboard
- `/ponytail-help` — quick reference card
