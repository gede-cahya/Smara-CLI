# Smara CLI v1.20.69 Release Notes

**Release Date:** 2026-07-29

## 🚀 Highlights

- **Enhanced Discord PRD Wizard**: Expanded to 9 interactive quests including Tech Stack Preference and MVP Core Priority choices.
- **Contextual Domain PRD Generation**: Dynamically infers clean product names and synthesizes domain-specific PRD sections (Food & E-Commerce, Bot/Automation, SaaS, etc.) with Mermaid flowcharts, sequence diagrams, state transitions, and Gantt charts.
- **Process Environment Isolation**: Fixed RUSH mode sticky environment leakage across agent mode switches.

## 📦 Changes

- `feat(discord)`: Upgrade PRD wizard to 9 Quests with Tech Stack and MVP Priority options
- `feat(discord)`: Contextual domain-aware PRD Markdown generator with Mermaid diagrams
- `fix(agent)`: Isolate process environment when toggling agent execution modes
- `release`: Bump version to v1.20.69
